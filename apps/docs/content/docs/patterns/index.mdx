How TelamonJS apps are built. Read the relevant pattern **before** changing a CRUD module, a form,
a dialog, a detail page or a dashboard.

<Callout type='warn' title='Architecture'>
  Data flows Client → REST API in one hop (cookie auth), through **React Query**.
</Callout>

## Critical Rules

<Callout type='error' title='Dynamic Zustand selectors inside custom hooks loop forever'>
  A dynamic selector inside a custom hook causes an infinite loop (`getSnapshot should be
  cached`). Subscribe to the store and select locally. See
  [Zustand Selector Pattern](/docs/patterns/zustand-selector).
</Callout>

```ts
// ✅ CORRECT
const formState = useFormStore()
const data = formState.forms[formId]

// ❌ WRONG (inside a custom hook)
const data = useFormStore(state => state.forms[formId])
```

- `config.tsx` starts with `'use client'`.
- `query.queryFn` resolves `PaginatedResponse<T>`, and every `mutationFn` resolves
  `{ success, data? }` — adapt inside the `mutationFn`, not in the API client.
- There is no `'select'` field type: use `'relationship'` with `loadField`.

## A Complete CRUD Module

```
app/admin/users/
├── config.tsx          'use client' — CrudConfig (module config + data layer)
├── page.tsx            <ListPage config={config} />
└── [id]/
    └── page.tsx        Detail Page (optional — the view dialog covers most cases)

lib/api/
└── users-client.ts     list / get / create / update / delete against the API
```

```tsx title="config.tsx"
'use client'
import { type CrudConfig } from '@telamonjs/ui'
import { usersApi } from '@/lib/api/users-client'

export const config: CrudConfig<User, UserFormData> = {
  module: { name: 'users', title: 'Users', description: 'Manage system users', route: '/admin/users' },
  list: { title: 'Users', description: 'Registered users', columns, searchPlaceholder: 'Search...' },
  form: { sections, validation: validationSchema },
  // queryFn resolves PaginatedResponse<User> ({ data, total, page, pageSize, totalPages })
  query: { queryKey: ['users'], queryFn: usersApi.list },
  mutations: {
    // mutationFn resolves { success, data? } — shape it here, not in the API client
    create: {
      mutationFn: async data => ({ success: true, data: await usersApi.create(data) }),
      invalidates: [['users']],
    },
    update: {
      mutationFn: async ({ id, data }) => ({ success: true, data: await usersApi.update(id, data) }),
      invalidates: [['users']],
    },
    delete: {
      mutationFn: async ({ id }) => {
        await usersApi.delete(id)
        return { success: true }
      },
      invalidates: [['users']],
    },
  },
}
```

```tsx title="page.tsx"
import { ListPage } from '@telamonjs/ui'
import { config } from './config'

export default function UsersPage() {
  return <ListPage config={config} />
}
```

## Anti-Patterns

- ❌ A dynamic Zustand selector inside a custom hook (see above)
- ❌ `type: 'select'` — use `'relationship'` with `loadField`
- ❌ Server Actions, `actions.ts` or `unstable_cache` as the data layer
- ❌ `className: 'w-full'` on a form field — the grid ignores it; use `span`
- ❌ `any` — use `unknown` or the real type
- ❌ `redirect()` inside `try`/`catch` — the `NEXT_REDIRECT` error is caught; redirect outside the block
- ❌ Looking for React Query hooks in `@telamonjs/ui` — they are not re-exported; import `@tanstack/react-query` directly
