Reference for all **36 field types** registered in the telamonjs-ui field system (list them with `getAvailableFieldTypes()`). Use these in `FormSection.fields[].type`.

<Callout type='error' title="'select' does NOT exist">
  There is no `'select'` field type. **Always use `'relationship'`** for
  dropdowns.
</Callout>

```typescript
// ❌ NEVER use 'select' (does not exist) — and there is no `options` prop either
{ name: 'category', type: 'select', options: [...] }

// ✅ ALWAYS use 'relationship'; options come from `loadField`
{
  name: 'category',
  label: 'Category',
  type: 'relationship',
  loadField: async () => [
    { value: 'a', label: 'Category A' },
    { value: 'b', label: 'Category B' },
  ],
}
```

`loadField` has the type `() => Promise<IOption[]> | ((search, id, dependsOn?) => Promise<IOption[]>)`:
return the options directly (`IOption` is `{ value: string | number; label }`), or return a
search function for server-side filtering of large lists. Pair it with `dependsOn` to reload
options when another field changes.

## Quick Reference

| Field Type | When to Use | Special Props |
| --- | --- | --- |
| `'text'` | Simple text | `placeholder` |
| `'email'` | Validated email | `placeholder` |
| `'password'` | Password | `placeholder` |
| `'textarea'` | Long text | `placeholder` |
| `'number'` | Integer | `placeholder` |
| `'float'` | Decimal number | `placeholder` |
| `'boolean'` | On/off switch | `default` |
| `'checkbox'` | Checkbox | `default` |
| `'date'` | Date | `minDate`, `maxDate` |
| `'datetime'` | Date + time | - |
| `'masked-datetime'` | Masked date/time | `mask` |
| **`'relationship'`** | **Dropdown / select** | `loadField`, `dependsOn` |
| `'multiselect'` | Multiple select | `loadField`, `dependsOn` |
| `'image'` | Image upload | `uploadFn`, `path` |
| `'file'` | File upload | `uploadFn`, `path`, `resolveUrl` |
| `'masked'` | Masked input (CPF, phone) | `mask`, `maskType` |
| `'component'` | Custom component | `Component` |
| `'crud'` | Nested data 1:N | See [CRUD Field Pattern](/docs/patterns/crud-field) |
| `'hidden'` | Hidden field | - |

Every field also accepts `name`, `label`, `type`, `required`, `description`, `placeholder`,
`span`, `readOnly`, `default`, `editOnly` and `visibleWhen`.

## Field Width in BaseForm

BaseForm uses CSS Grid (not flexbox), so `className='w-full'` is ignored. Use `span` instead, matching the section `grid` value:

```typescript
// span must match the section grid value (default '2')
{ name: 'fullWidthField', type: 'relationship', span: '2' }
// For grid='3' sections, use span='3' for full width
```
