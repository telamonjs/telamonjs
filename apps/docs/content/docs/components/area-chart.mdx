Area chart component built on Recharts for visualizing volume over time —
optionally stacked to show how parts compose a total.

<AreaChartPreview />

<Callout type='info' title='Built on Recharts'>
  All chart components are built on [Recharts](https://recharts.org/) with
  pre-configured theming and responsive behavior. Recharts ships with
  `@telamonjs/ui` — no separate install.
</Callout>

---

## Basic Usage

```tsx
import { AreaChart } from '@telamonjs/ui'

const data = [
  { name: 'Mon', visits: 1200 },
  { name: 'Tue', visits: 1900 },
  { name: 'Wed', visits: 1500 },
  { name: 'Thu', visits: 2200 },
  { name: 'Fri', visits: 2600 },
]

export default function TrafficChart() {
  return <AreaChart data={data} dataKeys={['visits']} />
}
```

<Callout type='warn' title='The X axis reads the `name` field'>
  Like the other charts, `AreaChart` takes flat `dataKeys: string[]`, one area per key, with the
  X axis fixed to the `name` field.
</Callout>

## Examples

### Stacked Areas

```tsx
const data = [
  { name: 'Jan', organic: 4000, paid: 2400, referral: 800 },
  { name: 'Feb', organic: 3000, paid: 1398, referral: 900 },
  { name: 'Mar', organic: 5000, paid: 3200, referral: 1100 },
]

<AreaChart
  data={data}
  dataKeys={['organic', 'paid', 'referral']}
  stacked
/>
```

Use `stacked` when the series sum to a meaningful total (traffic sources,
revenue streams); leave it off to compare independent trends.

### Overlapping Comparison

```tsx
<AreaChart
  data={data}
  dataKeys={['thisYear', 'lastYear']}
  colors={['#3b82f6', '#94a3b8']}
/>
```

### With React Query

```tsx
'use client'

import { AreaChart } from '@telamonjs/ui'
import { useQuery } from '@tanstack/react-query'
import { metricsApi } from '@/lib/api/metrics-client'

export function TrafficBySource() {
  const { data = [] } = useQuery({
    queryKey: ['traffic-by-source'],
    queryFn: metricsApi.trafficBySource,
  })

  return <AreaChart data={data} dataKeys={['organic', 'paid']} stacked />
}
```

## Best Practices

1. **Stack only real compositions** - Stacked areas imply the total matters
2. **Order stacked series** - Largest/most stable series at the bottom
3. **Name the X axis field `name`** - Map API data if needed
4. **Prefer LineChart for many series** - Overlapping areas get muddy past 2-3 series
