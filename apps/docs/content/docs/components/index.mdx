title: Components

---

Every component is exported by `@telamonjs/ui`; each page lists its props and
examples. A CRUD module rarely touches most of them directly: `ListPage` renders the
list, the dialogs and the forms from a [`CrudConfig`](/docs/getting-started/crud-config),
and [Module structure](/docs/patterns/admin-module-structure) shows a complete module.
Not sure which one fits? See the [decision trees](/docs/reference).

## Shell & Layout

| Component | What it is |
| --- | --- |
| [AdminShell](/docs/components/admin-shell) | The app shell: sidebar, Cmd+K command palette and breadcrumb |
| [AppShell](/docs/components/app-shell) | Lower-level layout primitive; use `AdminShell` unless it cannot express your shell |
| [ModernSidebar](/docs/components/modern-sidebar) | Hierarchical sidebar with string icons, composed by `AdminShell` |
| [CommandPalette](/docs/components/command-palette) | Keyboard-driven palette (Cmd+K) for navigation and actions |
| [Breadcrumb](/docs/components/breadcrumbs) | Breadcrumb primitives and the route-aware breadcrumb of the shell |
| [Tabs](/docs/components/tabs) | Tab navigation between related views |
| [ShellPage](/docs/components/shell-page) | Full-height page container with fullscreen support |
| [AdminHeader](/docs/components/admin-header) | Page header bar: title, icon, description, status, fullscreen toggle |
| [AdminTabs](/docs/components/admin-tabs) | `ContentTabs` that fill the height of a shell page |
| [TabToolbar](/docs/components/tab-toolbar) | Filters, search and actions inside a tab panel |

## CRUD & Data

## Standalone Pages

Create, edit and view happen in dialogs by default. These pages are for forms that
outgrow a dialog; see [Standalone form pages](/docs/patterns/edit-page).

| Component | What it is |
| --- | --- |
| [CreatePage](/docs/components/create-page) | Page wrapper for a create form |
| [EditPage](/docs/components/edit-page) | Page wrapper for an edit form, with tabs |
| [BaseFormPage](/docs/components/base-form-page) | The shared base of both, for full control |

## Forms
