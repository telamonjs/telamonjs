Tab navigation component for organizing and switching between related content views or sections.

<Callout type='info' title='Content Organization'>
  `Tabs` help organize related information without cluttering the interface or
  requiring page navigation.
</Callout>

---

## Basic Usage

```tsx
import {
  Tabs,
  TabsList,
  TabsTrigger,
  TabsContent,
} from '@telamonjs/ui'

export default function SettingsPage() {
  return (
    <Tabs defaultValue='profile'>
      <TabsList>
        <TabsTrigger value='profile'>Profile</TabsTrigger>
        <TabsTrigger value='account'>Account</TabsTrigger>
        <TabsTrigger value='security'>Security</TabsTrigger>
      </TabsList>

      <TabsContent value='profile'>{/* Profile settings */}</TabsContent>

      <TabsContent value='account'>{/* Account settings */}</TabsContent>

      <TabsContent value='security'>{/* Security settings */}</TabsContent>
    </Tabs>
  )
}
```

---

## Props

`Tabs`, `TabsList`, `TabsTrigger` and `TabsContent` are styled [Radix Tabs](https://www.radix-ui.com/primitives/docs/components/tabs)
parts and accept the Radix props. The ones you use most:

```typescript
// Tabs (Radix Tabs.Root)
{
  defaultValue?: string // Initial active tab
  value?: string // Controlled active tab
  onValueChange?: (value: string) => void // Tab change callback
  orientation?: 'horizontal' | 'vertical' // Arrow-key direction (default 'horizontal')
  activationMode?: 'automatic' | 'manual' // default 'automatic'
  className?: string
  children: React.ReactNode
}

// TabsTrigger (Radix Tabs.Trigger)
{
  value: string // Tab identifier (required)
  disabled?: boolean // Disable tab
  className?: string
  children: React.ReactNode // Tab label — put icons and badges here
}

// TabsContent (Radix Tabs.Content)
{
  value: string // Tab identifier (required)
  forceMount?: true // Keep mounted while inactive
  className?: string
  children: React.ReactNode
}
```

`TabsTrigger` has no `icon` or `badge` prop. For a data-driven tab bar with icons and badges,
use [`ContentTabs`](/docs/components/admin-tabs) (`TabItem.icon` / `TabItem.badge`).

### Controlled Tabs

```tsx

import { useState } from 'react'

export default function ControlledTabs() {
  const [activeTab, setActiveTab] = useState('tab1')

  return (
    <>

      <Tabs value={activeTab} onValueChange={setActiveTab}>
        <TabsList>
          <TabsTrigger value='tab1'>Tab 1</TabsTrigger>
          <TabsTrigger value='tab2'>Tab 2</TabsTrigger>

        <TabsContent value='tab2'>Content 2</TabsContent>
        <TabsContent value='tab3'>Content 3</TabsContent>

```

### Vertical Tabs

```tsx
<Tabs defaultValue='general' orientation='vertical' className='flex gap-4'>
  <TabsList className='h-auto flex-col items-stretch'>
    <TabsTrigger value='general'>General</TabsTrigger>
    <TabsTrigger value='appearance'>Appearance</TabsTrigger>
    <TabsTrigger value='notifications'>Notifications</TabsTrigger>
    <TabsTrigger value='privacy'>Privacy</TabsTrigger>
  </TabsList>

  <TabsContent value='general'>{/* Content */}</TabsContent>
  <TabsContent value='appearance'>{/* Content */}</TabsContent>
  <TabsContent value='notifications'>{/* Content */}</TabsContent>
  <TabsContent value='privacy'>{/* Content */}</TabsContent>

```

Layout: Tabs on left, content on right. `orientation` only switches arrow-key navigation to
up/down — the column layout comes from the classes.

## URL Sync (Optional)

**Sync active tab with URL:**

```tsx
'use client'

import { useSearchParams, useRouter } from 'next/navigation'

export default function URLSyncedTabs() {
  const router = useRouter()
  const searchParams = useSearchParams()
  const tab = searchParams.get('tab') || 'overview'

  function handleTabChange(value: string) {
    const params = new URLSearchParams(searchParams)
    params.set('tab', value)
    router.push(`?${params.toString()}`)
  }

  return (
    <Tabs value={tab} onValueChange={handleTabChange}>
      {/* Tabs */}
    </Tabs>
  )
}
```

Now tabs persist through page reloads and can be bookmarked/shared. `useTabUrlSync` from
`@telamonjs/ui` packages this pattern: `const { activeTab, setTab } = useTabUrlSync({ tabs: ['overview', 'reports'] })`.

## Best Practices

1. **Limit tabs** - 3-7 tabs optimal (use dropdown for more)
2. **Short labels** - 1-2 words per tab
3. **Related content** - Only group related content
4. **Default tab** - Choose most important/common tab
5. **Persist state** - Remember active tab (localStorage or URL)
6. **Lazy load** - Load content when tab activated
7. **Responsive** - Stack or scroll on mobile

## Accessibility

- ✅ Keyboard navigation (Tab, Arrow keys, Home, End) — from Radix Tabs
- ✅ ARIA roles (`tablist`, `tab`, `tabpanel`)
- ✅ `aria-selected` and `aria-controls`
- ✅ Focus management
- ✅ Screen reader announcements
- ✅ Disabled state properly communicated

**Keyboard shortcuts:**

- `Tab` - Move focus into the tab list (active trigger), then into the panel
- `Arrow Left/Right` - Navigate between tabs (`Up/Down` with `orientation='vertical'`)
- `Home/End` - First/last tab
- `Enter/Space` - Activate focused tab (with `activationMode='manual'`; otherwise focus activates)
