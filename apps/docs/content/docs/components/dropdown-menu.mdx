Dropdown menu component for displaying contextual actions, options, and navigation in a floating menu.

<Callout type='info' title='Built on Radix UI'>
  `DropdownMenu` uses [Radix

  accessible, keyboard-friendly interactions.
</Callout>

---

## Basic Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
} from '@telamonjs/ui'
import { MoreVertical } from 'lucide-react'

export default function ActionsMenu() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger>
        <MoreVertical className='w-4 h-4' />
      </DropdownMenuTrigger>

      <DropdownMenuContent>
        <DropdownMenuItem>Edit</DropdownMenuItem>
        <DropdownMenuItem>Duplicate</DropdownMenuItem>
        <DropdownMenuItem>Delete</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

## Components

```typescript
// Main container
<DropdownMenu>
  <DropdownMenuTrigger />  // Trigger button
  <DropdownMenuContent>    // Floating menu
    <DropdownMenuItem />   // Menu item
    <DropdownMenuSeparator />  // Divider
    <DropdownMenuLabel />  // Section label
    <DropdownMenuSub />    // Submenu (with SubTrigger + SubContent)
  </DropdownMenuContent>
</DropdownMenu>
```

  The root barrel exports: `DropdownMenu`, `DropdownMenuTrigger`,

  `DropdownMenuGroup` or `DropdownMenuPortal`: use labels + separators for

## Complete Example

```tsx title="components/row-actions-menu.tsx"
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuSub,
  DropdownMenuSubTrigger,
  DropdownMenuSubContent,
} from '@telamonjs/ui'
import {
  MoreVertical,
  Edit,
  Copy,
  Download,
  Share2,
  Trash2,
} from 'lucide-react'
import { Button } from '@/components/ui/button'

interface RowActionsMenuProps {
  row: { id: string }
  onEdit: (id: string) => void
  onDuplicate: (id: string) => void
  onDelete: (id: string) => void
}

export default function RowActionsMenu({
  row,
  onEdit,
  onDuplicate,
  onDelete,
}: RowActionsMenuProps) {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button variant='ghost' size='icon'>
          <MoreVertical className='w-4 h-4' />
          <span className='sr-only'>Open menu</span>
        </Button>
      </DropdownMenuTrigger>

      <DropdownMenuContent align='end'>
        <DropdownMenuItem onClick={() => onEdit(row.id)}>
          <Edit className='w-4 h-4 mr-2' />
          Edit
        </DropdownMenuItem>

        <DropdownMenuItem onClick={() => onDuplicate(row.id)}>
          <Copy className='w-4 h-4 mr-2' />
          Duplicate
        </DropdownMenuItem>

        <DropdownMenuSeparator />

        <DropdownMenuSub>
          <DropdownMenuSubTrigger>
            <Download className='w-4 h-4 mr-2' />
            Export
          </DropdownMenuSubTrigger>
          <DropdownMenuSubContent>
            <DropdownMenuItem onClick={() => exportAs(row.id, 'csv')}>
              Export as CSV
            </DropdownMenuItem>
            <DropdownMenuItem onClick={() => exportAs(row.id, 'excel')}>
              Export as Excel
            </DropdownMenuItem>
            <DropdownMenuItem onClick={() => exportAs(row.id, 'pdf')}>
              Export as PDF
            </DropdownMenuItem>
          </DropdownMenuSubContent>
        </DropdownMenuSub>

        <DropdownMenuItem onClick={() => shareRecord(row.id)}>
          <Share2 className='w-4 h-4 mr-2' />
          Share
        </DropdownMenuItem>

        <DropdownMenuSeparator />

        <DropdownMenuItem
          onClick={() => onDelete(row.id)}
          className='text-destructive focus:text-destructive'
        >
          <Trash2 className='w-4 h-4 mr-2' />
          Delete
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

## Use Cases

- **Row actions** - Table row operations (edit, delete, etc.)
- **User menus** - Profile, settings, logout
- **Context menus** - Right-click or click actions
- **Bulk actions** - Operations on selected items
- **Settings** - Theme, language, preferences
- **Navigation** - Quick access to pages

---

## Best Practices

1. **Group related actions** - Use separators and labels
2. **Destructive actions last** - Place delete/remove at bottom
3. **Show shortcuts** - Display keyboard shortcuts
4. **Use icons** - Improve scanability
5. **Align properly** - Use `align` prop for positioning
6. **Limit items** - 5-10 items max (use submenu for more)
7. **Disable when needed** - Show disabled state for unavailable actions

- ✅ Keyboard navigation (Tab, Arrow keys, Enter, Esc)
- ✅ Focus management
- ✅ ARIA roles and attributes
- ✅ Screen reader announcements
- ✅ Focus trap within menu
- ✅ Escape to close

**Keyboard shortcuts:**

- `Space/Enter` - Open menu
- `↓` - Next item
- `↑` - Previous item
- `→` - Open submenu
- `←` - Close submenu
- `Esc` - Close menu
- `Home/End` - First/last item
