`telamonjs add admin invitations`: email invitations for apps generated by `telamonjs create`, in both layouts. Adds an `Invitation` Prisma model (only the sha256 of the link's token is stored, 7-day expiry, `EXPIRED` computed on read), `invitations.read`/`invitations.write`, `GET/POST /invitations`, `POST /invitations/:id/resend` (rotates the token), `PUT /invitations/:id/revoke`, and the public `GET /invitations/by-token/:token` and `POST /invitations/accept` (creates the user with the invited roles and marks the invitation accepted in one transaction; every unusable token gets the same 410). The web side gets `/admin/convites` (invite dialog, resend/revoke row actions) and a public `/convite/<token>` page that creates the account and signs in. Mail goes through a port the app implements, console-only by default: `sendMail()` in `src/lib/mail.ts`, or the `MAIL_SENDER` provider of `apps/api/src/modules/mail` in the monorepo. The accept link is built from `NEXTAUTH_URL`, noted in `.env.example`.
