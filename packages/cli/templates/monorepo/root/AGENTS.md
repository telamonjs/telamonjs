## What lives where

- **Route Handlers are gone from `apps/web/src/app/api/usuarios`.** The
  `usuarios` CRUD now lives in `apps/api` (`/v1/usuarios`) — `apps/web`
  calls it through `src/lib/api/client.ts` (SuperJSON, `credentials:
  'include'`). Only `apps/web/src/app/api/auth/[...nextauth]` remains: the
  NextAuth session itself is issued by the web app, `apps/api` only decodes
  the cookie it produces.
- **Prisma lives in `packages/shared` only.** `apps/web` and `apps/api`
  import the singleton client from `{{scope}}/shared/prisma` — never
  instantiate `PrismaClient` anywhere else.
- **`packages/shared` never imports `next` or `next-auth`.** The NextAuth
  config (`apps/web/src/auth.ts`) stays in the web app; the API decodes the
  session cookie itself. Both sides share the `@telamonjs/auth` contract:
  `createAuthCallbacks()` in the web app, `createJwtAuthGuard()` in the API
  (see `apps/api/CLAUDE.md`).

## Commands

```bash
pnpm dev              # apps/web, port {{appPort}}
pnpm dev:api          # apps/api, port {{apiPort}}, prefix /v1
pnpm worker           # apps/jobs BullMQ worker
pnpm scheduler        # apps/jobs repeatables
pnpm build            # shared -> api -> web
pnpm type-check       # every package

pnpm lint:telamonjs   # CrudConfig/dialogs conventions, apps/web only
pnpm db:push          # prisma db push (packages/shared)
pnpm db:seed          # admin@example.com / 12345
pnpm telamonjs:link   # @telamonjs/ui from ../telamonjs (hooks unlink around commits)
pnpm telamonjs:unlink # back to the published range
docker compose up -d  # postgres + redis, dev-only ports
```

## Gotchas

- **Traefik `/v1` priority.** Traefik ranks routers by rule length by
  default, not registration order — `traefik/dynamic.yml` sets
  `priority: 100` on the `/v1` router so it doesn't lose to the bare
  `Host()` catch-all for the web app.
- **`{{scope}}/shared/prisma` path alias.** `apps/web/tsconfig.json`
  and `apps/api/tsconfig.json` map a literal `"{{scope}}/shared/prisma"`
  entry in `paths` — the generic `"{{scope}}/shared/*"` wildcard resolves
  `.../shared/src/*`, which does NOT cover `./prisma` (that maps to
  `src/lib/prisma`, not `src/prisma`). Keep both entries if you touch the
  aliases.
- **`serverExternalPackages`.** `apps/web/next.config.js` lists
  `{{scope}}/shared` there — it uses Prisma and Node built-ins
  (`fs`, `crypto`) that must never enter the webpack/Turbopack bundle.
- **`tsx --env-file=../../.env`.** `apps/jobs` loads the root `.env`
  explicitly on every script since it has no framework doing it for it.
- **`rawBody: true`.** `apps/api`'s Nest app is created with `{ rawBody:
  true }` so any future webhook can verify an HMAC signature over the raw
  request body — don't drop it when touching `main.ts`.
- **`packages/shared/tsconfig.json` has `declaration: false`.** It's
  consumed via the `exports` map against compiled `dist/*.js`, not via
  project references — emitting `.d.ts` there is dead weight.
- **`.gitignore` patterns have no leading `/`** for `.next/` and similar —
  in a monorepo they'd otherwise only match at the repo root and miss
  `apps/web/.next`.
